Dulces

Junta tres o más iguales

Movimientos 0
Objetivo
Puntos0
Desliza un dulce hacia una casilla vecina, o toca dos dulces seguidos, para cambiarlos de sitio. Si se juntan 3 o más iguales en línea, desaparecen. 4 en línea crean un dulce rayado, una L o una T crean uno envuelto y 5 en línea, una bomba de color. Cambia dos especiales entre sí para hacer un combo. Con teclado: flechas para moverte, Intro para elegir un dulce y una flecha para cambiarlo. H muestra una pista.
